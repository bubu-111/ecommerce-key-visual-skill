# 类别与视觉方向参考

本表只用于**缺少调性线索时的起步参考**：不是适用范围、不是强制分类，也不是通用合规清单。本 Skill 适用于任意商品品类——下表的类别只是常见举例，未列出的品类按该商品的实际购买决策自行分析并声明。用户品牌规范、目标受众与事实资料始终优先于本表。

| 常见类别（举例） | 可参考调性 | 信息侧重 |
| --- | --- | --- |
| 食品饮料 | 温暖、新鲜、日常 | 味道、原料、份量；仅采用有依据描述 |
| 美妆个护 | 干净、精致、通透 | 使用感、成分、已提供证据支持的功效 |
| 服饰鞋包 | 简洁、生活化 | 面料、版型、搭配与真实外观 |
| 数码家电 | 精准、冷静 | 性能、规格及测试条件 |
| 家居母婴 | 温和、有秩序 | 使用便利、材质和适用条件 |
| 运动户外 | 轻快、耐用感 | 使用场景、工艺、已证实性能 |

许可、认证、年龄或特殊声明等要求，应根据具体商品、展示位和有效官方依据判断；区分包装标识与主视觉必须呈现的内容。不能把同一要求泛化到整类商品。用户资料内的重要限制条件要保留。
