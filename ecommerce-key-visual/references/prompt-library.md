# 背景生成指导

生成工具只负责背景；商品和 Logo 从原素材合成，文字由代码排版。

提示词结构：场景/氛围 + 商品与文字预留区域 + 与商品匹配的视角和光线 + 品牌色调 + 材质 + 约束。按所选构图写，不强制左字右图。

示例（通用示例，按当前商品与方向替换，不构成固定要求）：简洁的生活场景，右侧预留放置真实商品的位置，左侧平整低细节留白用于文案；柔和侧光与原商品照一致，浅色哑光台面，克制的商业摄影背景。画面不生成文字、数字、Logo、水印、签名、界面或商品本体。

按工具支持的提示词/负面参数表达上述约束，不要求所有工具原样接受同一英文串。

先生成一张背景试片，叠真实商品及文案检查整体；确需修改时给出具体问题。默认总计不超过三次生成尝试，超过时报告原因或使用代码背景；用户明确追加且有新方向时可继续。

逐张检查：无文字/Logo/水印；无代画商品；文字和商品区域可用；光向、视角与色温相容；裁切缩放后构图仍有效。水印处置按实际工具可用导出和素材条件决定，不统一裁掉固定比例；没有可用背景则换方案。

记录实际提示词、工具、背景文件及重出原因；多语种优先共享一张背景，不因语言变化重复生图。
