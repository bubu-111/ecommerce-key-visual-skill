# 规格确认

不把过时或无来源的推荐值当作平台硬要求。

1. 提取用户明确的宽高、比例、展示位、格式、体积上限、安全区和文字限制；尺寸与比例冲突时询问。
2. 已指定展示位且没有完整规格时，查询可访问的官方说明，记录链接、核验日期、适用位置/类目；区分最小值、推荐值与上限。
3. 无法查证时标“平台要求待核验”，可制作设计草稿，不能保证可上传。用户指定规格也不等于平台适配已验证。
4. 无任何规格时采用项目默认 800×800 PNG；安全区取**短边的 5%**（1080×1350 → 四边各 54px），允许按实际要求调整。只有比例时，未有其他依据可取短边 800px 推导整数宽高并声明。

规格记录：用途/展示位、宽×高、格式、体积上限（未知可空）、四边安全区、其他限制、依据/链接、核验日期、待确认项。

商品主图、信息流广告、笔记封面和直播封面分别确认；不要只按平台名称套一张表。比例或平台变化后重新排版、核对内容限制及导出，不只拉伸旧成图。
